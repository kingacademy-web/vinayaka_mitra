# 🪔 వినాయక మిత్ర (Vinayaka Mitra)
### Complete Production-Ready Devotional Flutter + Firebase App

A devotional companion app for **Vinayaka Chavithi** and daily Hindu worship in **Telugu & English** featuring:

- 🪔 **16 Shodashopachara Pooja Vidhanam** with interactive checklist, Sanskrit mantras, and required Samagri list.
- 🌿 **21 Sacred Eka Vimshathi Pathri** dataset with botanical names, mantras, and medicinal benefits.
- 🎶 **Harathulu Library & Reader** across 9 Hindu deities with Telugu lyrics, English transliteration, and spiritual meanings.
- 📖 **Vinayaka Vratha Katha** (Ganesha Jananam, Syamantaka Mani Katha & Chandradarshana Dosha Nivarana).
- 🥥 **Festive Prasadam / Naivedyam Recipes** (Undrallu, Kudumulu, Modak, Bellam Thalikalu, Pulihora).
- 📍 **Pandal & Immersion Ghat Map** with geolocation and markers.
- ⚡ **3-Tier Offline-First Architecture** with Hive box storage and packaged asset seeds.
- 🔔 **Push Notifications & Admin CRUD Panel**.

## Automated Cloud APK Build (GitHub Actions)
This repository includes an automated GitHub Actions workflow [`.github/workflows/build_apk.yml`](.github/workflows/build_apk.yml) that automatically builds the Android Release APK upon push.

To download the APK:
1. Go to the **Actions** tab on GitHub.
2. Click on the latest workflow run.
3. Download **Vinayaka-Mitra-Release-APK** from the **Artifacts** section!
